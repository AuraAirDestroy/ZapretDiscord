> [!WARNING]
>
> ### АНТИВИРУСЫ
> Антивирус может отреагировать на WinDivert.  
> Для работы zapret нужен WinDivert — инструмент перехвата и фильтрации сетевого трафика.
> Его используют и легальные, и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Цитата из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы считают файлы WinDivert рискованными или относят их к хакерским инструментам. В результате файл удаляется и отправляется в карантин. В названии такого обнаружения обычно есть `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky для этого есть настройка «Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда». Если вы уверены в настройке исключений, рекомендуется добавить исключение. Если не уверены, безопаснее отключить обнаружение PUA.

## ⚙️ Использование

1. Активируйте безопасный DNS (Secure DNS).
    * В Chrome включите «Использовать безопасный DNS» и укажите поставщика DNS, отличный от варианта «Поставщик по умолчанию».
    * В Firefox откройте «DNS через HTTPS», установите режим «Персональный», выберите «Выбрать провайдера/поставщика» и укажите URL вручную. Например: `https://dns.google/dns-query` (Cloudflare может быть заблокирован).
    * Windows 11 позволяет включить Secure DNS в параметрах системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Этот способ рекомендуется пользователям Windows 11.
    * На роутерах Keenetic включите параметр «Транзит запросов». Если его отключить, настройка и работа Secure DNS на компьютере могут нарушиться.

2. Загрузите ZIP- или RAR-архив с [последнего релиза](https://github.com/AuraAirDestroy/zapret-discord-youtube/releases/latest).

3. Откройте свойства скачанного архива и отметьте «Разблокировать». При распаковке через 7-Zip или PeaZip этот шаг не нужен.

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите нужный скрипт.
    * Для поиска работающей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Чтобы добавить стратегию в автозапуск, выберите **`service.bat`** -> `Install Service` -> подходящую стратегию.

## ℹ️ Кратко о файлах

- [**`general.bat ...`**](./general.bat) — запуск стратегии вручную.

  Ручной запуск подходит для проверки стратегий. Их результат зависит от множества условий. **Переберите разные варианты (ALT, FAKE и другие), чтобы найти подходящий для вас.**

- [**`service.bat`**](./service.bat) — управление автозапуском и другие инструменты:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск (services.msc).</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб.
  - **`Check Status`** — посмотреть состояние обхода и служб (автозапущенной стратегии и WinDivert).
  - **`Game Filter`** — включить или отключить обход для игр и других служб, работающих по UDP и TCP на портах выше 1023.  
  После смены режима стратегию нужно перезапустить.  
  Текущее состояние (включено/выключено) показано в скобках.
  - **`IPSet Filter`** — изменить режим фильтрации сервисов, перечисленных в `ipset-all.txt`.  
  Режим полезен при проверке ресурса, который доступен без zapret, но не работает с ним.  
  В скобках отображается текущее состояние:
    - `none` — проверка IP не выполняется.
    - `loaded` — IP сверяются со списком.
    - `any` — фильтр применяется к любому IP.  
  - **`Auto-Update Check`** — включить или отключить автоматическую проверку обновлений.
  - **`Replace active fakes`** — подменить используемый фейк на другой из каталога `bin`.
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>.
  - **`Check for Updates`** — проверить наличие обновлений.
  - **`Run Diagnostics`** — найти распространённые причины сбоев zapret.  
  В конце проверки можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это может помочь, если приложение внезапно перестало работать.
  - **`Run Tests`** — проверить стратегии с помощью встроенной утилиты:
    - `Standard tests` — проверка сайтов, перечисленных в `utils/targets.txt`.
    - `DPI checkers` — проверка DPI у разных провайдеров (Cloudflare, Amazon и других).


## ☑️ Частые вопросы и неполадки

### Скрипт `general*` запущен, но ничего не происходит

- При отдельном запуске стратегии (не через service) должен открыться `winws.exe` — процесс обхода, видимый на панели задач.  
Если процесс не появился, ознакомьтесь с [#522](https://github.com/AuraAirDestroy/zapret-discord-youtube/issues/522).

### Не нашлась подходящая стратегия
- Откройте командную строку с правами администратора.
- По очереди выполните команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер.

### Не открывается веб-версия Telegram
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts устарел, вам предложат обновить его вручную:  
  - Скопируйте весь текст из открывшегося Блокнота.
  - Откройте файл `hosts` в созданном каталоге в текстовом редакторе, запущенном от имени администратора.
  - Вставьте скопированное в конец `hosts` (или замените уже добавленный ранее аналогичный текст).
  - Сохраните файл и проверьте подключение. Если проблема осталась, убедитесь, что изменения в `hosts` действительно сохранены.

#### Работа не гарантируется. Если способ не помог, используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/AuraAirDestroy/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем перестать работать.**
> Стратегия, которая раньше помогала, может перестать работать после обнаружения.
> В репозитории есть несколько вариантов обхода. Если ни один не подошёл, создайте собственную стратегию на основе одной из имеющихся и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` откройте `Run Diagnostics` и проверьте, нет ли ошибок.

- Убедитесь, что адрес ресурса включён в списки доменов или IP.

- Переключитесь на другие стратегии, например **`ALT`** или **`FAKE`**.

- Попробуйте полностью переустановить zapret (см. раздел ниже).

- Дополнительная информация: [#765](https://github.com/AuraAirDestroy/zapret-discord-youtube/issues/765).

### Как выполнить полное обновление или переустановку?
- Сохраните ресурсы и данные, которые добавили самостоятельно.
- Перезапустите устройство.
- В `service.bat` выберите `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; устраните найденные ошибки, а в конце введите Y.
- Удалите каталог zapret.
- Скачайте свежую версию (`zapret-discord-youtube-...`) со [страницы релизов](https://github.com/AuraAirDestroy/zapret-discord-youtube/releases).
- Щёлкните правой кнопкой по архиву и откройте свойства. Если внизу справа есть флажок «Разблокировать», отметьте его, нажмите «Применить», затем «ОК».
- Распакуйте архив в новый каталог в корне диска, без пробелов и специальных символов.
- Запускайте разные скрипты `general` по очереди и проверяйте доступ к ресурсам. Если доступ не появился, закройте программу (значок замка на панели задач) и испытайте следующую стратегию.
- Найдя рабочий вариант, добавьте его в автозапуск через `service.bat` -> `Install Service` и выберите стратегию.

### Игра или приложение не работает при включённом zapret

- В `service.bat` убедитесь, что `Game Filter` имеет статус **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть ресурсы, которые вы не собирались ограничивать.

### Античит сообщает о WinDivert

- Следуйте [инструкции](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

### В Windows 7 требуется цифровая подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть в списке служб

1. В командной строке Windows (Win+R, `cmd`) определите название службы:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её, подставив найденное название вместо `название_из_первого_шага`:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS настроен](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если раньше всё работало, попробуйте остальные стратегии.
- См. обсуждение [#251](https://github.com/AuraAirDestroy/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала выясните, какая стратегия открывает YouTube, и запустите её.
- В `service.bat` выберите `Run Diagnostics` и очистите кэш Discord.
- Проверьте, помогла ли очистка в приложении Discord.
- Откройте Discord в браузере: https://discord.com/app. Если браузерная версия работает, можно пользоваться ею.
- Если Discord не работает и в браузере, повторно проверьте все стратегии: YouTube и Discord иногда требуют разных вариантов.
- См. обсуждение [#252](https://github.com/AuraAirDestroy/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/AuraAirDestroy/tg-ws-proxy).
- Другой вариант — бесплатные MTProto-прокси из интернета.

### Не запускаются игры

Игры различаются, поэтому проверить и исправить каждую из них невозможно.

Чаще всего помогает такой порядок:
- Через `service.bat` обновите ipset и включите `Game Filter`.
- Если результата нет, дополнительно включите параметр `ipset any`.

Учтите: режим `ipset any` может помешать открытию многих сайтов. Не оставляйте его включённым постоянно. Вместо этого выясните IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если это не решило проблему, создайте обсуждение в разделе [Discussions](https://github.com/AuraAirDestroy/zapret-discord-youtube/discussions), а не issue, и дождитесь ответа других игроков.

### Не нашли ответ на свой вопрос

- Опишите проблему [здесь](https://github.com/AuraAirDestroy/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Дополнить перечень адресов для обхода можно в следующих файлах:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** — домены-исключения, например, если IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно.
- **`ipset-all.txt`** — IP-адреса и подсети.
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
